# Canvas Portfolio Website Template

A fully customisable, premium brutalist canvas portfolio website template. Designed for artists, designers, developers, and directors who want their work showcased in a unique, interactive, non-linear format.

Live Demo: [kostiskounadis.xyz](https://kostiskounadis.xyz/)

---

## ▩ Template Philosophy
1. **Interactive Canvas Layout**: The website functions as an infinite-feeling 2D draggable stage where media elements are scattered.
2. **Brutalist Minimalism**: Pinned typography, high-contrast states, and micro-interactions give the portfolio a bold, premium aesthetic.
3. **No Scroll Engine**: Conventional vertical scrolling is replaced with canvas panning, zooming, scattering, and layout transitioning.
4. **Static Performance**: The output is 100% static HTML, CSS, and JS — easily deployable for free on Cloudflare Pages, Netlify, or Vercel.

---

## ▤ Features
- **3 Layout Modes**: Random Scatter, Rows, and Stacks.
- **Dynamic Category Filtering**: Filter by category with smooth transitions.
- **Customizable Themes & Typography**: Fully customisable colours, fonts, background effects, and text animations via a setup GUI.
- **Local GUI Setup Tool**: A built-in local Node.js server that launches a gorgeous GUI to customize every aspect of your site without editing code directly.

---

## ▧ Quick-Start Outline
1. **Bootstrap & Install**: Verify you have Node.js installed on your machine.
2. **Launch Setup GUI**: Run the double-clickable command launcher or run `node admin/setup-server.js` in terminal.
3. **Add Media**: Drop your image or video files in `assets/images/` under the corresponding category folders.
4. **Publish**: Deploy the static build files to Cloudflare Pages, Netlify, or your preferred static host.
