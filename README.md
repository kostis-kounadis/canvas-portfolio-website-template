# Canvas Portfolio Template & Setup Dashboard

This project is a two-part ecosystem:
1. **The Template**: A highly interactive, brutalist, non-scrolling canvas portfolio.
2. **The CMS/Admin Dashboard**: A React-based visual configurator that allows anyone to customize the template without touching code.

This dual-architecture allows the project to be as powerful as a full CMS while exporting to a completely static, free-to-host HTML/JS output.

---

## 📂 Project Structure

This repository is strictly separated into two domains:

```text
/
├── template/                        <-- The actual Portfolio Website
│   └── (index.html, main.js, style.css, etc.)
│
├── admin/                           <-- The Setup CMS / GUI Dashboard
│   ├── app/                         <-- The compiled React dashboard
│   ├── server/                      <-- Node.js backend to save config
│   └── build-setup-app/             <-- React source code for developers
│
├── start-setup.command              <-- macOS 1-click launcher for users
└── start-setup.sh                   <-- Linux/Windows launcher for users
```

### 1. The Template (`/template`)
This is the final product. It is a completely static frontend. There is no build step for the template itself. It relies entirely on vanilla HTML, CSS, and JS. The visual look and feel is dictated by `config.json`, which is generated by the Admin dashboard.

*To deploy your portfolio, you simply point your hosting provider (Vercel, Netlify, Cloudflare Pages) to publish the `template/` directory.*

### 2. The Admin Dashboard (`/admin`)
This is the setup GUI. It is a modern React application built with Vite, Tailwind, and Shadcn UI. It runs locally on your machine via a lightweight Node.js server. 
When you make visual changes in the dashboard, the Node server writes those changes to `template/config.json`.

## 🚀 Quick Start for Users

If you just want to build your portfolio using this template:

1. **Install Node.js** (Required to run the local dashboard).
2. **Add your media** into `template/assets/images/<category>/`.
3. **Launch the Dashboard**:
   - **Mac:** Double-click `start-setup.command`
   - **Windows/Linux:** Run `bash start-setup.sh`
4. The dashboard will open at `http://localhost:3000/admin/`.
5. Customize your site, click "Build", and then deploy the `template/` folder online!

---

## 🛠️ For Developers

If you want to modify the React Admin Dashboard itself:
1. Navigate to the React source: `cd admin/build-setup-app/`
2. Install dependencies: `./install-gui-deps.sh` (or `npm install`)
3. Run the dev server: `./start-gui-dev.command` (or `npm run dev`)
4. Build the dashboard: `npm run build` (This exports to `admin/app/`)
